# Master Thief authored artwork

The PNGs in this folder are source sheets retained for review and future art
direction. They were generated on 2026-08-12 with the built-in image
generation tool from the prompts recorded in the task history. Runtime art is
derived into `assets/images/`; no source sheet is loaded by the browser except
the two atlases used for responsive cropping.

The game keeps decision-critical visuals procedural: floorplan nodes, route
lines, dice, modifier chips, controls, ordinary chrome, and achievement foil.
That keeps DCs, modifiers, assignment, injury, payout, and touch targets crisp
at 1280x720 and narrow WebGL sizes.
